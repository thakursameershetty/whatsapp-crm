Webhook (delivery status and Inbox)

To see delivered, read and failed, and to receive replies in the Inbox, add this in Meta App Dashboard → WhatsApp → Configuration → Webhook and subscribe to the messages field. It must be a public HTTPS address (deploy the app, or use ngrok while testing).

AI assistant

Gemini by Google has a free tier, which is enough for development and demos. To get a key:

  1. Go to aistudio.google.com/apikey and sign in with a Google account.
  2. Click Create API key and copy it.
  3. Paste it here, click Save, then Test.

On the free tier Google may use what you send to improve its products, and there's a limit on requests per minute and per day. Avoid real customer data, or switch to Claude.

Claude by Anthropic is paid per use (a few cents per request) and isn't included in a Claude.ai subscription. To get a key:

  1. Sign in or sign up at console.anthropic.com.
  2. Add credit under Settings → Billing; you can set a monthly limit there.
  3. Open Settings → API keys → Create key and copy it. It's only shown once.
  4. Paste it here, click Save, then Test.

Either way, for an attached file the assistant only sees the column names, the first five rows (with phone numbers partly hidden) and summary counts. It can't send anything on its own: every campaign it plans waits for your approval.

Uses Claude Opus 5.5.

Lead assistant (Inbox)

When someone writes to you, the AI drafts a reply that helps them and moves them toward becoming a lead. It saves what it learns (need, budget, timeline, status) to their contact, and flags the chat when a person should take over. Every reply is a draft: you send or edit it in the Inbox. It uses the AI provider chosen above.

Getting your API credentials

  1. Go to developers.facebook.com/apps, create an app of type Business and add the WhatsApp product.
  2. In WhatsApp → API Setup, add and verify each business phone number. Copy each number's Phone number ID and the WhatsApp Business Account ID.
  3. Create a permanent token: Business Settings → Users → System users → add an Admin system user → assign your app and WhatsApp account → Generate token with whatsapp_business_messaging and whatsapp_business_management.
  4. Create message templates in WhatsApp Manager → Message templates and wait for approval.
  5. Here: Numbers → Add number for each phone, Templates → Sync from Meta, then switch Demo mode off.

New numbers start with a daily limit on unique recipients (as low as 250/day) that rises while your quality stays high. Only message people who opted in. Blocks and reports lower your quality rating and can get numbers restricted.
