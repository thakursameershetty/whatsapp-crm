Demo mode
Simulate sending. Switch off to send real WhatsApp messages.

Webhook (delivery status and Inbox)

To see delivered, read and failed, and to receive replies in the Inbox, add this in Meta App Dashboard → WhatsApp → Configuration → Webhook and subscribe to the messages field. It must be a public HTTPS address (deploy the app, or use ngrok while testing).

Getting your API credentials

  1. Go to developers.facebook.com/apps, create an app of type Business and add the WhatsApp product.
  2. In WhatsApp → API Setup, add and verify each business phone number. Copy each number's Phone number ID and the WhatsApp Business Account ID.
  3. Create a permanent token: Business Settings → Users → System users → add an Admin system user → assign your app and WhatsApp account → Generate token with whatsapp_business_messaging and whatsapp_business_management.
  4. Create message templates in WhatsApp Manager → Message templates and wait for approval.
  5. Here: Numbers → Add number for each phone, Templates → Sync from Meta, then switch Demo mode off.

New numbers start with a daily limit on unique recipients (as low as 250/day) that rises while your quality stays high. Only message people who opted in. Blocks and reports lower your quality rating and can get numbers restricted.
